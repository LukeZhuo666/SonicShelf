# B-SIDE｜私人音乐发现系统

**把收藏夹里的音乐视频，整理成一座可以持续探索的私人唱片架。**

B-SIDE 面向喜欢音乐内容、也习惯收藏短视频的人。它将散落在收藏夹中的现场、翻唱、混剪和音乐推荐，重新组织为个人音乐档案，让“收藏过”进一步变成“找得到、看得懂、愿意再次打开”。

## 产品思路

传统收藏夹按时间堆叠内容，用户很难按音乐风格重新发现旧收藏。B-SIDE 借用唱片与 CD 的实体媒介意象，把音乐内容从线性列表转化为可浏览的主题空间。

整个体验围绕三步展开：

1. **整理内容**：将视频归入爵士、嘻哈、R&B、电子、民谣、电影配乐等音乐类别。
2. **重新发现**：通过 CD 架和唱片式浏览，快速回到特定音乐主题与视频。
3. **继续聆听**：根据浏览和收藏偏好生成私人 FM 歌单，并说明推荐缘由。

## 体验亮点

- **以唱片架替代普通列表**：让音乐分类成为页面的主要视觉和导航方式。
- **让内容更容易理解**：类别、标签与摘要帮助用户识别视频是什么、适合何时重看。
- **为收藏建立后续路径**：从单条内容浏览延伸至基于个人偏好的歌单探索。

## AI 在产品中的位置

AI 用于理解音乐内容并辅助归类、总结偏好和生成推荐说明。项目也包含音乐类型识别流程：视频音轨可用于分类，再映射到产品内的音乐类别。推荐模块将用户行为转换为具体歌单、场景和推荐理由。

## 项目信息

- **方向**：音乐内容整理与个性化发现
- **体验关键词**：私人档案、唱片隐喻、内容理解、个性化推荐
- **技术**：HTML、CSS、JavaScript、Three.js、FastAPI
