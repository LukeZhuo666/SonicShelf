# B-SIDE

> 让收藏过的音乐视频，成为值得反复打开的私人唱片架。

**LukeZ 过往作品独立展示。** 这里是为报名准备的案例介绍，不包含原项目源码或素材；项目详情、协作者与贡献记录以[原项目仓库](https://github.com/eiddiedev/B-SIDE)为准。

## 项目概览

B-SIDE 将音乐视频收藏重组为可浏览、可理解、可继续推荐的个人音乐档案。

## 展示重点

- 3D CD 架承载不同音乐类型，让内容归档变成直观的浏览体验。
- 分类、标签与 AI 摘要解释内容特征和推荐理由。
- B-SIDE FM 根据浏览与收藏习惯组织私人音乐视频歌单。

## 技术与体验关键词

HTML · CSS · JavaScript · Three.js · FastAPI
