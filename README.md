# 音架（SonicShelf）

音架是一款可直接使用的个人音乐影像收藏工具。把喜欢的现场、翻唱和音乐视频收进自己的唱片架，按风格和场景整理，之后可以搜索、筛选、播放和备份。

## 开始使用

打开 [音架](https://lukezhuo666.github.io/SonicShelf/)，填写作品名称与视频链接，选择音乐风格和聆听场景，点击“加入我的唱片架”。选中唱片卡片可以播放支持的 YouTube 或 Bilibili 视频。

## 功能

- 按音乐风格筛选，搜索标题与艺人
- 收藏喜欢的内容，按名称或加入时间排序
- 内嵌播放支持的公开视频链接
- 导出 JSON 备份，或从 JSON 恢复收藏
- 收藏数据保存在本地浏览器，无需注册

示例唱片用于初次体验，可以直接删除。浏览器清理站点数据前，请先导出备份。
